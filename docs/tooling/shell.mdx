`feather shell` drops you into a Python shell with the application context already pushed.
It's the quickest way to answer a question about your data, and the safest way to fix a
row by hand.

Loaded for you:

- `app`, the Flask application instance
- `db`, the SQLAlchemy database instance
- Every model from your `models/` directory

```bash
feather shell
```

## Example session

```python
Feather Interactive Shell
========================================

Available variables:
  User: type
  Post: type
  app: Flask
  db: SQLAlchemy

>>> User.query.count()
42
>>> user = User.query.filter_by(email='admin@example.com').first()
>>> user.role = 'admin'
>>> db.session.commit()
```

## In production

Reach it with `docker compose exec web feather shell`, or over SSH on the server.

| Task | Example |
| --- | --- |
| Check user status | `User.query.filter_by(email='...').first()` |
| Count records | `Post.query.count()` |
| Fix data issues | `user.active = True; db.session.commit()` |
| Debug queries | `User.query.filter_by(role='admin').all()` |
| Run one-off operations | Direct database work when needed |

<Tip>
  Install IPython with `pip install ipython` and the shell uses it automatically, for tab
  completion and syntax highlighting.
</Tip>
