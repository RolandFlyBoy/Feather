---

Available for authenticated apps, single-tenant or multi-tenant.

```bash .env
RESEND_API_KEY=re_xxxx                      # from https://resend.com/api-keys
RESEND_FROM_EMAIL=noreply@yourdomain.com    # must be verified in Resend
```

## Sending

```python
from services.email_service import EmailService

email_service = EmailService()

result = email_service.send(
    to="user@example.com",
    subject="Welcome!",
    body="Thanks for signing up."
)

result = email_service.send(
    to="user@example.com",
    subject="Your Report",
    body="<h1>Monthly Report</h1><p>...</p>",
    html=True
)
```

## Reporting the result

Return a toast from the HTMX response rather than redirecting:

```python
response = make_response(render_template("partials/email_sent.html"))

if result["success"]:
    response.headers["HX-Trigger"] = json.dumps({
        "showToast": {"message": result["message"], "type": "success"}
    })
else:
    response.headers["HX-Trigger"] = json.dumps({
        "showToast": {"message": result["error"], "type": "error"}
    })
```

<Tip>
  Send from a [background job](/features/background-jobs) rather than inline. A slow
  provider should not slow the response, and a failed send should be retryable.
</Tip>

## Admin tools

With email enabled, the admin panel gains a **Send Email** form at `/admin/tools`, with a
user search dropdown.
