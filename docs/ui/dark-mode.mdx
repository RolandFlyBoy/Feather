---
title: "Dark mode"
description: "A toggle on every page that survives navigation, with no flash of the wrong theme while the page loads."
icon: "moon"
---

Every scaffolded app includes a dark mode toggle that persists across pages in a `dm`
cookie. The toggle sits in the header of every page, including the admin panel.

## How it works

<Steps>
  <Step title="The cookie is read before first paint">
    A `dark-mode.js` script loaded in `<head>` reads the `dm` cookie and applies a `.dark`
    class to `<html>` before first render, so the wrong theme never flashes.
  </Step>
  <Step title="Any element can toggle it">
    Clicking an element carrying `data-toggle-dark-mode` toggles the class and updates the
    cookie.
  </Step>
  <Step title="Styles respond through a custom variant">
    All CSS uses `dark:` variants via Tailwind's custom variant:
    `@custom-variant dark (&:where(.dark, .dark *))`.
  </Step>
</Steps>

## The toggle button

Scaffolded into your templates:

```html
<button data-toggle-dark-mode
        class="p-2 rounded-lg text-gray-500 hover:bg-gray-200 dark:text-gray-400 dark:hover:bg-gray-700 transition-colors"
        title="Toggle dark mode">
    <span class="dark:hidden"><span class="material-symbols-outlined">bedtime</span></span>
    <span class="hidden dark:inline"><span class="material-symbols-outlined">sunny</span></span>
</button>
```

The script only looks for the `data-toggle-dark-mode` attribute. Which icon shows is
plain `dark:` variants on the two spans. To keep the markup cleaner, move the swap into
`app.css` and give the button your own class:

```css app.css
.dark-mode-toggle .icon-light { @apply dark:hidden; }
.dark-mode-toggle .icon-dark  { @apply hidden dark:inline; }
```

## Writing dark-mode-aware styles

Include `dark:` variants for every color-related class. Feather prefers CSS classes with
`@apply` over inline Tailwind, so dark mode support looks like this:

```css app.css
.my-card {
    @apply bg-white dark:bg-gray-800 text-gray-900 dark:text-gray-100
           border border-gray-200 dark:border-gray-700;
}
```

<Tip>
  Utility classes in markup instead of `@apply` in `app.css` are reported by
  [`feather check`](/tooling/check) as the `inline-tailwind` warning. Keeping styles in
  the stylesheet is what makes a dark mode audit a single-file read.
</Tip>
